# Suno prompt pack: "If I Had a Hundred-Fifty Points"

Paste-ready inputs for [Suno](https://suno.com) **Custom** mode. The lyrics below are generated from `README.md`. The whole song fits in one lyric box (under Suno's 5,000-character limit), so no Extend step is needed.

## About the voice

These prompts describe a *style* (smooth, playful, feel-good funk crooner with a half-sung, half-talked delivery). They don't clone Carolina MiC or any other real person's voice. Suno rejects artist names in the style box anyway. Generate 4–6 takes and keep the one whose vibe fits best.

## Style box

```
retro funk, 80s boogie, feel-good party groove, 104 bpm, F major, slap bass, electric piano stabs, synth brass hits, handclaps, male vocal, smooth warm baritone, playful half-sung half-rapped delivery, charismatic, comedic, corny and confident, call-and-response backing vocals
```

## Exclude styles

```
trap, heavy 808, autotune, dark, aggressive, metal, EDM drop
```

## Settings
- **Title:** If I Had a Hundred-Fifty Points (Wizards League Remix)
- **Vocal gender:** Male
- **Weirdness / Style influence** (if shown): Weirdness low (~30%), Style influence high (~70%) to keep it on-genre.

## Three ways to put it together
1. **All Suno (fastest):** the style box and lyrics produce a new beat and vocal together. The beat will be Suno's own funk track.
2. **Your beat + Suno vocal:** upload `beat.wav` (the original instrumental in this folder) and use Suno's **Add Vocals** / cover-from-upload feature if your plan has it. Paste the same lyrics and style box. The arrangement gives each person four bars (two bars per lyric line).
3. **Your beat + your voice (funniest for the league):** open `beat.mid` in GarageBand (or drop `beat.wav` into CapCut) and record the vocal on your phone.
